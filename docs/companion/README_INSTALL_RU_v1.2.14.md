# Установка Companion 1.2.14

1. Полностью замените Project Instructions содержимым `01_PROJECT_INSTRUCTIONS_v1.2.14.md`.
2. Оставьте по одной активной копии knowledge-модулей `00–15`.
3. Используйте `08_PHASE_CONTRACT_AND_PROGRESS_POLICY.md`; старые архивные модули не загружайте.
4. Создайте новый чат в том же Project и передайте актуальный restart bootstrap.
5. В рабочем цикле Companion показывает владельцу только понятное резюме, а техническое задание передаёт через JSON Action Packet.
