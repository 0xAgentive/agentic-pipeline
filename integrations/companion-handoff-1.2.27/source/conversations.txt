# ==============================================================================
# Antigravity Companion Handoff — Фильтр диалогов (Conversation ID Filter)
# ==============================================================================
# Этот файл позволяет указать, для каких конкретно диалогов Antigravity должен
# автоматически формироваться архив LATEST_CONTEXT.zip и копироваться в буфер обмена.
#
# ПРАВИЛА И СИНТАКСИС:
# ------------------------------------------------------------------------------
# 1. По умолчанию (если файл пуст, содержит только комментарии или символ *):
#    -> Handoff формируется для ВСЕХ диалогов во всех проектах.
#
# 2. РЕЖИМ БЕЛОГО СПИСКА (Allowlist):
#    Если вы укажете один или несколько Conversation ID (по одному на строку),
#    handoff будет создаваться ТОЛЬКО для этих диалогов. Все остальные диалоги
#    будут моментально пропускаться.
#    Пример:
#    4e568acf-a6a6-48f1-8b08-789a4210a93b   # Диалог проекта H10
#
# 3. РЕЖИМ ИСКЛЮЧЕНИЙ (Denylist):
#    Если перед ID поставить знак ! или -, этот диалог будет ИСКЛЮЧЁН из handoff.
#    Пример:
#    !45b895c8-25ef-4621-8426-41581f56c0ea  # Исключить этот диалог
#
# 4. ФИЛЬТРАЦИЯ ПО ИМЕНИ ПРОЕКТА / ПАПКИ:
#    Можно указывать имена папок проектов с префиксом @ или project:
#    Пример:
#    @H10 Athlete Cardio Lab
#    @Huawei Health export
#    !@Demo-PulseTracker                     # Исключить проект Demo
#
# 5. КОММЕНТАРИИ:
#    Символы #, // и ; в начале строки или после ID считаются комментариями.
# ==============================================================================
