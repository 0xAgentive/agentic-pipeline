# Runtime Truth — Execution Lease and Single Closure

A capability is active only when its project-local files and validators exist and pass.

- command inventory authorizes commands;
- execution lease authorizes writes;
- audit coverage matrix establishes first-audit completeness;
- reviewer attestation establishes audit independence;
- stage firewall protects scientific phase boundaries;
- compiled run result and closure state supersede stale prose and hand-authored status files.

Hashes remain internal trust-boundary metadata. They are not a routine owner approval mechanism.
