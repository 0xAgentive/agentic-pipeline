AGENTIC PIPELINE v1.2.27

🧭 Интерактивный Атлас Команд и Скиллов

Полная визуальная карта всех инструментов, слэш-команд и скиллов экосистемы для человека и ИИ-агентов.

🔍
/new-project Pipeline Core
agentic-project-scaffold
Создаёт новый проект под ключ по одному названию (Git + рантайм 1.2.27 + Action Bridge + начальный ZIP для ChatGPT). Или подключает существующий проект в режиме /adopt-project.
/new-project MyCoolApp
/companion-pack Pipeline Core
companion-project-context-pack
Упаковывает 100% чистой архитектуры проекта в легковесный ZIP (1–2 МБ) для ChatGPT/Claude, вырезая гигабайты node_modules, дампов датчиков и логов.
/companion-pack
/nextphase Исполнение
Запуск задачи Action Packet
Считывает скачанный от Компаньона пакет задачи с диска, проходит через Stage Firewall, пишет код, запускает тесты и выдаёт понятный 4-пунктовый отчёт.
/nextphase
/goal Режим упорства
Максимальная автономность
Модификатор для долгих задач на 15–60 минут. Приказывает агенту не останавливаться ни при каких сомнениях до полного зелёного прохождения всех тестов.
/nextphase /goal
/auditphase Аудит
Независимый аудит фазы
Строгая инспекция кода без внесения изменений: прогон матрицы приёмки, сверка точности метрик, проверка на утечки данных и запрещенные формулировки.
/auditphase
/fixcritical Ремонт
Устранение критических дефектов
Изолированно устраняет дефекты, зафиксированные аудитом в FINDINGS.json, и повторно перепроверяет только затронутую область.
/fixcritical
/fastpatch Патч
Быстрый точечный патч
Применяет мелкие правки (1–3 строки, опечатки, конфиги) с минимальными накладными расходами без тяжелого полного цикла валидации.
/fastpatch
interview-me Мышление
Инженерный допрос требований
ИИ задает вам по одному точному вопросу за раз, докапываясь до реальной цели идеи, пока уверенность в требованиях не достигнет 95%.
«Проведи интервью через interview-me»
tdd Инженерия
Разработка через тестирование (TDD)
Обязывает сначала написать падающий тест на новую функциональность или баг, и только потом писать минимальный рабочий код.
«Примени test-driven-development»
code-review Качество
Сквозное рецензирование кода
Проводит глубокий аудит изменений по 5 ключевым осям: корректность, читаемость, архитектура, безопасность и быстродействие.
«Проведи code-review-and-quality»
/stitch-sync Pipeline Core
stitch-design-sync
Извлекает цветовую схему, шрифты и компоненты из вашего приложения и синхронизирует живые UI-экраны в Google Stitch через Stitch MCP.
/stitch-sync
security Безопасность
Харднинг и аудит безопасности
Проверяет санитайзинг пользовательского ввода, защиту от XSS/инъекций, утечки персональных данных и строгость валидации схем.
«Примени security-and-hardening»
